## GCAA_contentCheckModel - 敏感内容检测模型
- 一款基于PHP编写/训练的轻量化中文敏感内容检测模型
- 性能占用较小，部署条件少，响应速度快

**可直接点击访问最新版在线部署模型**  
[https://yhapi.qianlinjiaxi.qzz.io/QL-GCAA_contentCheckModel.html](https://yhapi.qianlinjiaxi.qzz.io/QL-GCAA_contentCheckModel.html)

**注意事项**
> 使用该模型您必须遵守本存储库许可证，  
> 使用开发者提供的在线部署模型时输入的检测文本可能会被模型用于自学习以提升检测能力。
